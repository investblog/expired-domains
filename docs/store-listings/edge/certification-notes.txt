Expired Domains — notes for certification

Purpose: saves domain lists from expireddomains.net pages the user opens (collect across pages, filter, export to CSV/TXT/clipboard). Unofficial; not affiliated with ExpiredDomains.net.

Account: expireddomains.net shows its lists only to signed-in users and e-mails a login code on every new device, so please register your own free account at https://www.expireddomains.net/register/ with any e-mail you can read. For a disposable address you can use MailBot (free, same developer): https://microsoftedge.microsoft.com/addons/detail/ofaahjfcjogpimmiocambhenlmagdhgj — or Telegram https://t.me/gotemailbot without installing anything.

How to test: see reviewer-notes.txt (same steps). A welcome tab opens once after installation. The toolbar icon opens the side panel; there is no popup.

Permissions: content script on expireddomains.net (reads the domain table of the open page), storage, unlimitedStorage (up to 10,000 domains with ~30 columns), sidePanel (list beside the site).

Network: none. No analytics, telemetry or remote code. Data stays in local browser storage.
