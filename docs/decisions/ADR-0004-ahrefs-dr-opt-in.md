# ADR-0004: проверка Ahrefs DR ключом пользователя — по желанию, в v1.1

Дата: 2026-11-20. Разбор и источники — [research/ahrefs-dr.md](../research/ahrefs-dr.md).
Меняет инварианты I1, I4, I5 [SPEC](../SPEC.md) начиная с v1.1; v1 остаётся без сети.

## Контекст
- У Ahrefs есть бесплатный эндпоинт Domain Rating, до 1000 доменов за запрос, без
  расхода units. С 2026-08-10 ему нужен ключ APIv3.
- Можно ли создать ключ в бесплатном аккаунте — **[не проверено]**: документация Ahrefs
  противоречит себе.
- **Решение пользователя (2026-11-20):** функция полезна в любом случае. Держатели платных
  аккаунтов Ahrefs — более продвинутая и платёжеспособная аудитория.
- Сейчас ядро продукта — «никаких сетевых запросов» (I1, I5), без host-разрешений (I4).

## Решение
- **Функция есть, но включается только по желанию пользователя.**
  - Разрешение `https://api.ahrefs.com/*` необязательное: `optional_host_permissions`
    в MV3, `optional_permissions` в Firefox MV2.
  - Браузер спрашивает его в момент включения функции. При установке предупреждений нет.
- **Запросы:**
  - только по кнопке «Проверить DR» для выбранных доменов или всей выборки фильтра;
  - только из background;
  - `POST /v3/public/domain-rating-free`, пачками до 1000;
  - при ответе 429 — пауза и повтор.
- **Наружу уходят только имена доменов.** Статистика, теги, заметки и источники остаются
  в браузере.
- **Ключ:**
  - вводит сам пользователь, хранится в `storage.local`;
  - не попадает в резервную копию и экспорт;
  - удаляется одной кнопкой.

  Ключа разработчика в расширении нет.
- **Данные:**
  - поля записи `dr` и `drCheckedAt` — пользовательские, захват их не меняет (как Ф20–Ф22);
  - фильтр «DR ≥» (Ф25);
  - колонка CSV `dr`;
  - рядом с каждым показанным значением — «Domain Rating by Ahrefs» со ссылкой на
    https://ahrefs.com/, как требует лицензия DR.
- **Expireddomains.net не затрагивается.** К сайту расширение по-прежнему не обращается
  (I2, I3).
- **Срок — v1.1.** Первая версия выходит без сети, с простым ревью в магазинах. В v1.1 одним
  изменением переписываются:
  - I1, I4, I5;
  - A1 и A8: запросы только к `api.ahrefs.com` и только после включения;
  - раздел «Expired Domains» политики на 301.st;
  - раскрытие данных в CWS и AMO.
- **В v1 заранее ничего не закладывается.** В v1.1 появляются новые поля записи, а
  резервная копия получает `version: 2`. v1.1 читает копии версий 1 и 2 (Ф27).

## Альтернативы
- **В v1.** Отклонено, потому что первое ревью в трёх магазинах и обещание «без сети»
  проще удержать без внешних запросов. Срок можно сдвинуть по решению пользователя.
- **Платные эндпоинты** (`site-explorer/domain-rating`, `batch-analysis`) с UR, трафиком и
  другими метриками. Отложено: они тратят units пользователя, а DR бесплатен.
- **Отдельное расширение-компаньон.** Отклонено: два расширения и обмен данными между
  ними сложнее, чем одно необязательное разрешение.

## Последствия
- **Ahrefs может изменить или закрыть эндпоинт без предупреждения** — это уже было
  2026-08-10. Функция должна сообщать ошибку понятно и ничего не ломать в остальном.
- Описание в магазинах и политика конфиденциальности различаются для v1 и v1.1.
- Нужно проверить на реальном ключе:
  - создаётся ли ключ в бесплатном аккаунте;
  - фактический лимит;
  - ответ при неверном ключе и при исчерпании лимита.
