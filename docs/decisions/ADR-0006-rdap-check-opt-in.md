# ADR-0006: проверка доменов в реестре (RDAP) по кнопке — по желанию, в v1.1

Дата: 2026-11-26. Дополняет [ADR-0004](ADR-0004-ahrefs-dr-opt-in.md): обе проверки
входят в v1.1 одним блоком «проверки по кнопке» и одним изменением I1/I4/I5
[SPEC](../SPEC.md).

## Контекст
- Статус «свободен / занят» и дата регистрации в списке берутся из таблицы
  expireddomains.net (Д8, Д8в). Таблица — снимок: к моменту покупки домен могли уже
  перехватить, а когда он освободится на самом деле, из неё не видно.
- RDAP — современная замена WHOIS. Реестры отдают по нему JSON: зарегистрирован ли домен,
  его статусы (`pendingDelete`, `redemptionPeriod` и др.), регистратора и даты. Ключ не
  нужен.
- Список RDAP-серверов по зонам публикует IANA (`https://data.iana.org/rdap/dns.json`). В
  нём все коммерческие gTLD и около трети национальных зон.
- Проверено 2026-11-26 (`curl` с заголовком `Origin`): справочник IANA, Verisign (.com/.net)
  и PIR (.org) отвечают `Access-Control-Allow-Origin: *`. Значит, со страницы расширения
  запросы, вероятно, проходят без host-разрешений — **[не проверено в живом расширении]**.
- Условия реестров: Verisign запрещает массовые автоматические запросы; DENIC (.de)
  разрешает запросы только для технических и административных целей.
- Решение пользователя (2026-11-26): проверку делать в этом расширении, а не в отдельном.
  Обещание «без сети» уже снимается решением по DR (ADR-0004), а RDAP ложится в тот же
  блок.

## Решение
- **Функция включается только по желанию пользователя** — переключателем в настройках,
  как DR.
- **Запросы:**
  - только по кнопке «Проверить в реестре» — для отмеченных доменов или выборки фильтра;
  - по одному, с паузой не меньше секунды; лимит на один запуск — десятки доменов, точное
    число — при реализации;
  - сервер зоны — из справочника IANA (его копия обновляется не чаще раза в сутки);
  - напрямую к серверу реестра; посредники вроде `rdap.org` не используются.
- **«Свободен» — только ответ 404 от сервера самого реестра.** Зона вне справочника,
  таймаут или ошибка — «не удалось проверить», без запасных источников.
- **Разрешения.** Сначала без них, если подтвердится CORS. Если какой-то нужный сервер его
  не отдаёт, — `optional_host_permissions` (MV3) / `optional_permissions` (Firefox MV2)
  поимённо на этот сервер, с запросом в момент включения. Широкие маски (`https://*/*`) не
  используются.
- **Наружу уходят только имена доменов** — серверам реестров их зон. Статистика, теги,
  заметки и источники остаются в браузере.
- **Данные:**
  - поля записи с результатом проверки (статус в реестре, статусы RDAP, регистратор,
    дата истечения, время проверки) — пользовательские, захват их не меняет (как Ф20–Ф22);
  - значения из таблицы ED не перезаписываются, результат реестра показывается рядом;
  - поля и фильтр описываются в SPEC перед реализацией.
- **Expireddomains.net не затрагивается.** К сайту расширение по-прежнему не обращается
  (I2, I3).
- **Срок — v1.1, вместе с DR.** Одним изменением переписываются:
  - I1, I4, I5;
  - A1 и A8: запросы только к `api.ahrefs.com`, `data.iana.org` и RDAP-серверам из
    справочника, только после включения и только по кнопке;
  - раздел «Expired Domains» политики на 301.st;
  - описания и раскрытие данных в CWS, Edge Add-ons и AMO.

## Альтернативы
- **Отдельное расширение «всё о домене».** Отклонено пользователем 2026-11-26: два
  продукта и обмен данными между ними сложнее, чем одна необязательная функция.
- **Редиректор `rdap.org`.** Отклонено: третья сторона видит запросы, а его 404 не
  отличает «свободен» от «зона не поддерживается».
- **WHOIS (порт 43).** Из браузера недоступен; для gTLD с 2025 года не обязателен.
- **API регистраторов.** Нужны ключи; к реестрам ближе и честнее обращаться напрямую.
- **Свой сервер.** Не делаем: данные пользователя не должны проходить через нас.

## Последствия
- Национальные зоны покрыты частично (например, .ru и .eu в справочнике не найдены) — для
  них честное «не удалось проверить».
- Реестры могут менять адреса и лимиты без предупреждения — ошибка проверки не должна
  ломать остальное.
- Результат — снимок на время проверки; рядом всегда показывается, когда проверено.
- Нужно проверить в живом расширении (Chrome, Edge, Firefox): проходят ли запросы без
  host-разрешений, ответы на несуществующий домен и на перегрузку (429).
