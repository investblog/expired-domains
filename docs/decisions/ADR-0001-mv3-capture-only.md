# ADR-0001: MV3-расширение с принципом «capture-only»

## Контекст
expireddomains.net запрещает автоматизацию и не отдаёт списки доменов файлом. Домены
показываются постранично в HTML-таблицах; часть списков доступна только авторизованным
(бесплатная регистрация).

## Решение
- Расширение Chrome Manifest V3: content script читает DOM страниц, **которые пользователь
  открыл сам**, background service worker складывает результат в `chrome.storage.local`,
  popup показывает список и экспортирует в CSV/TXT/clipboard.
- Никаких собственных HTTP-запросов расширения: ни фонового скачивания страниц, ни авто-
  пагинации, ни обхода пейволла. Расширение работает строго внутри открытой вкладки и
  не отличается от просмотра глазами с точки зрения сайта.
- Сбор — накапливающийся: пользователь листает страницы вручную, на каждой жмёт
  «Сохранить страницу» (или включает автосбор при открытии страницы).
- Парсер заголовочно-независимый: ищет таблицу с колонкой `Domain`, остальные колонки
  складывает в stats по имени заголовка — переживёт переименования/перестановку колонок.

## Последствия

> Пункты про лимит ~10 МБ и один ключ хранения заменены
> [ADR-0002](ADR-0002-storage-and-permissions.md). Устаревший фолбэк «ссылки на /domain/» и
> парсер по тексту заголовков заменены DOM-контрактом [SPEC](../SPEC.md), раздел 5.
> Плоский JS без сборки заменён проектом WXT, а Firefox собирается как MV2
> ([ADR-0003](ADR-0003-wxt-and-301-conventions.md)); принцип capture-only не меняется.

- Скорость сбора = скорость ручного листания; большие выгрузки требуют времени и не
  должны нарушать правила сайта (разумный темп просмотра — на пользователе).
- Лимит `chrome.storage.local` (~10 МБ) — порядка сотен тысяч доменов с stats; при
  приближении нужен экспорт и очистка (в коде есть счётчик, в TODO — проверка).
- Смена вёрстки сайта сломает селекторы — лечится правкой `content.js`.
